## Local preview

Install the dependencies described in the al-folio documentation, then run:

```bash
bundle install
bundle exec jekyll serve
```

Open http://localhost:4000.

## Updating the site

- Edit `_pages/about.md` for the homepage biography.
- Edit `_pages/research.md`, `_pages/teaching.md`, and `_pages/projects.md` for those sections.
- Update `_bibliography/papers.bib` and `_pages/publications.md` when adding verified publications.
- Update `_data/socials.yml` when profile links change.
- Use `assets/img/profile.svg` as a temporary avatar until a personal headshot is added.

No personal email address or unverified contact information is included. Replace the temporary avatar with a suitable professional photo when ready.
